# Reference materials

This folder holds project documentation and source files used to build the action site. It is **not part of the deployed application**.

| Path | Description |
|---|---|
| `build-brief.md` | Cursor build brief for this project |
| `style-guide.md` | Altagether action-oriented digital style guide |
| `partner-kit/` | Extracted Department of Angels HTML widgets and scripts |
| `assets/` | Original logo files and partner kit zip archive |

The live site is implemented natively in Next.js at the repository root (`src/`).
